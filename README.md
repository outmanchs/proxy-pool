## 一、核心架构与特性

1. **独立内置内核，零环境冲突**
   - 内置独立 `mihomo.exe` (Clash Meta) 内核，运行在独立端口与外部控制器下。
   - **完全隔离宿主系统的 Clash Verge / Clash for Windows**，互不干扰、无需修改系统全局代理。
2. **500+ 本地静态端口映射池**
   - 默认开放 `58001 ~ 58500` 连续本地端口（端口范围可启动时交互自定义）。
   - 每个端口独立对应一个远端健康节点，提供绝对固定的本地入口。
3. **HTTP / SOCKS5 双协议动态旋转网关**
   - **HTTP 旋转网关 (`127.0.0.1:17890`)**：支持随机轮换、延迟优先轮换、按 Session 会话保持（TTL 自定义）。
   - **Mixed 双协议网关 (`127.0.0.1:17891`)**：同时支持 HTTP 与 SOCKS5 代理连接。
   - 支持账号密码认证（如指纹浏览器所用的动态认证格式）与 IP 白名单免密访问。
4. **智能节点测速与端口自动修复**
   - 启动 3 秒全量扫描订阅节点；
   - 常规轮询仅检测已映射端口，没失效的不动，失效的秒级自动从备用池中换绑顶替；
   - 测速周期（默认 5 分钟）支持终端启动时配置与 Web 端动态修改。
5. **现代暗黑风 Web 可视化仪表盘**
   - 实时展示有效节点数、可用率、端口延迟排名、活跃连接与目标链接。
   - 提供节点搜索过滤、手动一键立即测速、测速周期动态调整等功能。

## 二、快速上手指南

### 1. 环境准备
- 操作系统：Windows 10 / 11 / Server (x64)
- Python 版本：Python 3.10 及以上
- 依赖安装：
  ```bash
  pip install -r proxy_pool/requirements.txt
  ```

### 2. 放置机场订阅文件
将机场导出的 Clash YAML 订阅文件放入 `proxy_pool/订阅yaml文件/` 目录下（支持放入多个不同机场的 `.yaml` 订阅文件）。

> 若使用订阅链接，可编辑 `proxy_pool/订阅yaml文件/subscribe.txt`，每行填入一条订阅 URL。

### 3. 配置网关凭据（环境变量）
为避免敏感凭据硬编码，网关认证密码通过环境变量注入。在项目根目录创建 `.env` 文件（参考 `.env.example`）：

```bash
PROXY_POOL_GATEWAY_USERNAME=xiaoshuazi_${sessionName}
PROXY_POOL_GATEWAY_PASSWORD=你的真实密码
```

> 未设置时密码回退为占位符 `CHANGE_ME`，也可在启动向导（模式 2）中动态设置。

### 3. 启动运行
在 `proxy_pool` 目录下双击 **`start.bat`**，或在命令行中运行：
```bash
python start.py
```

### 4. 启动模式选择
启动时终端将弹出交互选项：
```text
[启动选项]
  [1] 极速启动 (交互确认 58001 起始与终止端口，其他使用默认值)
  [2] 全参数配置向导 (逐项交互设置端口、网关、密码、测速等)
  [3] 订阅模式更新 (从 subscribe.txt 更新远程订阅链接)
```
- **模式 1（推荐）**：直接回车默认起始端口为 `58001 ~ 58500`，并可输入测速检测周期（如直接回车默认 300 秒，输入 600 为 10 分钟）。
- **模式 2**：逐项自定义网关端口、认证密码、轮换时长、测速并发等。

## 三、节点检测与健康维护机制

系统内置了高可靠性的多层级节点健康检测与自动故障转移机制：

| 检测阶段 | 触发时机 | 检测范围 | 维护与替换规则 |
| :--- | :--- | :--- | :--- |
| **首次启动全量扫描** | 服务启动后 3 秒 | 扫描合并配置文件中的**全部节点**（如 700+ 个） | 测定所有节点延迟，按优先级/延迟填充映射端口（58001~58500），剩余健康节点存入备用池。 |
| **周期性轮询检测** | 每 5 分钟 (可在 Web / 启动时修改) | 仅检测**当前已映射端口的 500 个节点** | **没失效的节点保持端口不动**；失效节点秒级从备用池调取可用节点进行热换绑。 |
| **手动即时测速** | Web 控制台点击 `⚡ 立即测速` | 即刻触发新一轮检测 | 异步执行并实时在 Web 端与终端显示最新结果。 |

### 终端完成摘要示例
每次检测完成后，控制台将输出结构化汇总：
```text
======================================================================
12:43:29 [+] 【节点检测完成摘要】(已映射端口节点检测)
12:43:29 [+]   · 节点检测统计: 共检测 500 个 | 有效 496 个 | 失败 4 个 (有效率: 99.2%, 成功: 496/500)
12:43:29 [+]   · 端口映射维护: 保持有效 492 个 | 自动替换失效 4 个 | 当前映射 500 个
12:43:29 [+]   · 本轮检测耗时: 41.5 秒
12:43:29 [+]   · 本次完成时间: 2026年09月01日 12:43:29
12:43:29 [+]   · 下次检测时间: 2026年09月01日 12:53:29 (将在 10 分钟后开始)
======================================================================
```

## 四、代理使用与第三方接入

### 1. 静态多端口模式 (指纹浏览器/多开)
系统启动后自动在 `proxy_pool/` 目录下生成导出文件：
- **`proxy_list.txt`**：带认证格式（适合批量导入 AdsPower、Hubstudio、比特指纹浏览器等）
  ```text
  127.0.0.1:58000:xiaoshuazi_58000:YOUR_PASSWORD
  127.0.0.1:58001:xiaoshuazi_58001:YOUR_PASSWORD
  ...
  ```
- **`静态代理ip.txt`**：纯地址格式
  ```text
  127.0.0.1:58000
  127.0.0.1:58001
  ...
  ```

### 2. HTTP/Mixed 动态网关模式 (爬虫/轮换)

#### (1) 网关基础信息
- **HTTP 动态网关**：`http://127.0.0.1:17890`
- **Mixed (HTTP/SOCKS5) 网关**：`http://127.0.0.1:17891` 或 `socks5://127.0.0.1:17891`
- **默认认证账号**：`xiaoshuazi`（支持扩展参数）
- **默认认证密码**：由环境变量 `PROXY_POOL_GATEWAY_PASSWORD` 配置（详见「快速上手」），未设置时回退为占位符 `CHANGE_ME`

#### (2) 动态 Session 会话保持与参数解析
网关支持类似海外商业代理（如 Nstproxy / BrightData）的用户名高级参数控制：
- **固定会话 IP（指定时间保持同一出口）**：
  ```python
  import requests

  # sessid 参数保持相同，代理池将在 TTL 内将请求固定在同一个远端 IP
  proxies = {
      "http": "http://xiaoshuazi_sessid-wallet01_ttl-300:YOUR_PASSWORD@127.0.0.1:17890",
      "https": "http://xiaoshuazi_sessid-wallet01_ttl-300:YOUR_PASSWORD@127.0.0.1:17890",
  }
  resp = requests.get("https://api.ipify.org?format=json", proxies=proxies)
  print(resp.json())
  ```
- **每次请求自动更换 IP**：
  不传 `sessid` 或将用户名设为随机值，每次 HTTP 请求网关将从健康节点池中自动轮换。

## 五、Web 可视化后台与控制台

启动服务后，浏览器访问：
👉 **`http://127.0.0.1:6001`**

### 仪表盘功能概览：
1. **状态指标卡**：实时查看【总节点数】、【有效节点】、【映射数量】、【可用率】、【最近一次更新时间】、【下次自动更新倒计时】；
2. **节点监控表格**：
   - 节点名称与归属订阅文件；
   - 本地监听端口（点击可直接测试连通性）；
   - 实时延迟（绿色低延迟 <500ms，黄色中延迟，红色高延迟）；
   - 节点使用状态（闲置中 / 使用中呼吸灯动效）；
   - 目标链接与来源业务标识。
3. **交互操作区**：
   - **搜索与过滤**：支持按节点名/端口关键词搜索、最大延迟过滤（如 ≤200ms）、只看使用中；
   - **动态修改测速周期**：下拉选择或输入自定义秒数，点击【保存周期】即刻生效；
   - **立即测速**：点击 `⚡ 立即测速` 通知后台异步重测。

## 六、RESTful API 接口文档

Web 服务（默认端口 6001）提供标准的 JSON / 纯文本接口，便于与其他程序和脚本对接：

| 接口路径 | 请求方法 | 说明 | 核心参数 / 示例响应 |
| :--- | :---: | :--- | :--- |
| **`/`** | GET | Web 管理后台首页 | 返回 HTML 仪表盘 |
| **`/api/status`** | GET | 获取代理池全局健康状态与统计 | `{"total_nodes": 766, "valid_nodes": 511, "last_update": "...", ...}` |
| **`/api/proxy/all`** | GET | 分页查询所有有效代理列表 | 支持 `page`, `per_page`, `search`, `max_ms`, `sort_by` 等参数 |
| **`/api/proxy/best`** | GET | 获取当前延迟最低的最优代理 | `{"status": "success", "port": 58012, "delay_ms": 112, ...}` |
| **`/api/proxy/random`** | GET | 随机抽取一个健康代理 | `{"status": "success", "port": 58045, "delay_ms": 180, ...}` |
| **`/api/proxy/top`** | GET | 获取延迟排名前 N 的代理 | `?n=10` 返回延迟最低的前 10 个节点 |
| **`/api/proxy/text`** | GET | 纯文本格式输出代理列表 | `?protocol=http&max_ms=500` 直接返回换行分隔的代理文本 |
| **`/api/settings/interval`** | POST | 动态修改测速轮询间隔 (秒) | `?interval=600` 将检测周期更新为 10 分钟 |
| **`/api/health/check`** | POST | 手动触发全量节点可用性测速 | `?wait=false` 立即进入后台异步检测 |
| **`/get` 或 `/random`** | GET | 兼容常见开源代理池提取格式 | 返回单个可用代理 JSON |

## 八、常见问题与排查 (FAQ)

### Q1: 运行提示端口被占用？
- 静态端口默认占用 `58001 ~ 58500`，动态网关占用 `17890 / 17891`，Web 后台占用 `6001`。
- 如果端口冲突，可在启动时选择 **模式 2（全参数配置向导）** 更改起始端口或网关端口。

### Q2: 为什么有些节点测速超时或不可用？
- 系统默认单节点测速超时为 `4000ms`（4 秒），最大允许延迟为 `3000ms`。
- 机场部分节点由于墙或服务器维护无法连通属于正常现象，系统会自动将其从 500 个端口映射中剔除，并由备用池中的健康节点顶替。

### Q3: 如何添加新的机场订阅？
1. 将新的 `.yaml` 订阅文件放入 `订阅yaml文件/` 目录；
2. 重启程序（`start.bat`），系统会自动解析所有 YAML 文件并重新合并生成配置文件。

### Q4: 如何修改密码或关闭网关认证？
- 推荐：在项目根目录的 `.env` 文件中设置 `PROXY_POOL_GATEWAY_PASSWORD`（参考 `.env.example`）；
- 或启动时选择 **模式 2（全参数向导）**，在 `[3/6]` 步骤中选择是否开启认证以及输入新密码。
